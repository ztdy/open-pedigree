# Open Pedigree（家系图）Mac 版安装说明

适用：**macOS 12（Monterey）及以上**。Intel 芯片和 Apple 芯片（M1/M2/M3/M4…）通用，同一个安装包。
（macOS 11 及更早版本无法运行。查看版本：屏幕左上角  →「关于本机」。）

## 1. 安装

1. 双击 `OpenPedigree-<版本>-mac.dmg`，会弹出一个窗口。
2. 把 **Open Pedigree** 图标拖进旁边的 **Applications（应用程序）** 文件夹。
3. 拖完后可以把 dmg 窗口关掉，在桌面或访达侧栏里右键「推出」这个磁盘。

## 2. 第一次打开（只需做一次）

本软件没有向苹果购买开发者签名，所以第一次打开时 macOS 会拦一下，这是正常的：

1. 在「应用程序」里双击 **Open Pedigree**，会提示「无法验证开发者」或「Apple 无法检查其是否包含恶意软件」，点 **完成**（不要点「移到废纸篓」）。
2. 打开 **系统设置 → 隐私与安全性**，往下滚到「安全性」一栏，会看到「已阻止使用 Open Pedigree」，点旁边的 **仍要打开**，输入电脑密码确认。
3. 再次打开软件，点 **打开**。之后就和普通软件一样，直接双击即可。

> macOS 14 及更早版本也可以：在「应用程序」里 **右键（或按住 Control 点按）→ 打开 → 打开**。
>
> 单位统一管理的 Mac 可能不允许放行未签名软件（看不到「仍要打开」按钮），这种情况请联系单位 IT。

### 如果提示「已损坏，无法打开」

「已损坏」也可能表示文件在传输中出错或被人改动过，**请先核对文件，再处理**：

1. 打开「终端」（在启动台或聚焦搜索里搜“终端”），输入下面这行（把路径换成你 dmg 实际所在的位置）后回车：

   ```
   shasum -a 256 ~/Downloads/OpenPedigree-0.2.1-mac.dmg
   ```

2. 把输出的一长串字符，和发给你的人提供的 **SHA-256 校验值**（随安装包一起的 `.sha256` 文件里的内容）对比：
   - **不一致**：不要安装，删掉文件，重新向对方索取。
   - **一致**：说明文件就是原版，只是被系统拦截。确认已经把软件拖进「应用程序」后，在终端执行下面这行，再打开软件：

     ```
     xattr -dr com.apple.quarantine "/Applications/Open Pedigree.app"
     ```

## 3. 数据保存在哪里

家系图文件默认保存在 `~/Library/Application Support/Open Pedigree/pedigrees/`（首次启动时也可以自选位置）。卸载软件（把应用拖进废纸篓）不会删除这些数据。

## 4. 更新

有新版本时软件会提示，点「打开下载页」下载新的 dmg，按第 1 步重新拖入「应用程序」并选择「替换」即可，数据不受影响。
